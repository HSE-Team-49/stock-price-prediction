# README: сравнение недельных моделей прогноза акций

## 1. Контекст задачи

Проект посвящён прогнозированию цен акций на недельном горизонте. В качестве исходных данных используются дневные котировки акций, которые агрегируются в недельные ряды. Модель строит прогнозы на горизонты от 1 до 52 недель вперёд.

Основная проверка качества выполняется на последнем годе фактических данных:

```text
2025-05-08 — 2026-05-08
```

Исторические данные до `2025-12-20` лежат в основном файле:

```text
data/prices_all.csv
```

Данные после `2025-12-20` до `2026-05-08` лежат в отдельном файле:

```text
data/prices_all_2025_12_20_today.csv
```

Макропоказатели считаются известными только до:

```text
2025-12-20
```

После этой даты будущие макропоказатели не используются как известные значения. Для недель после этой даты в признаках сохраняется последнее доступное макро-значение и дополнительные признаки возраста макроданных.

## 3. Целевая переменная

Модель прогнозирует логарифмическую доходность на горизонте `h` недель:

```text
target_logret_w{h} = log(price[t+h]) - log(price[t])
```

Где:

```text
h = 1, 2, ..., 52
```

После прогноза лог-доходности цена восстанавливается так:

```text
pred_price = feature_price * exp(pred_logret)
```

# 5. Версия 1: глобальная двухмодельная модель

Файл:

```text
global_xgb_weekly_h100_forecast_two_models.py
```

## 5.1. Идея модели

Это лучшая глобальная версия среди протестированных подходов.

В ней обучаются две модели XGBoost:

```text
short_macro
long_no_macro
```

Разделение по горизонту:

```text
1–13 недель   -> short_macro
14–52 недели  -> long_no_macro
```

## 5.2. Short-модель

```text
model_group = short_macro
horizons = 1..13
features = все признаки, включая макро
```

Short-модель использует макро, потому что на коротких горизонтах последнее известное макросостояние ещё может быть информативным.

## 5.3. Long-модель

```text
model_group = long_no_macro
horizons = 14..52
features = все признаки, кроме макро и производных макро
```

Long-модель не использует макро, потому что на дальних горизонтах будущие макропоказатели неизвестны, а замороженные значения могут стать слабым или искажающим сигналом.

## 5.4. Особенности подхода

Плюсы:

```text
простая архитектура
одна short-модель и одна long-модель
достаточно много данных на каждую модель
хорошая устойчивость по WAPE/MAPE
```

Минусы:

```text
модель глобальная и сглаживает различия между группами акций
одна long-модель обучается сразу на горизонтах 14–52
кластеризация используется только как признак, а не как способ разделения обучения
```

# 6. Версия 2: кластерные модели

Файл:

```text
global_xgb_weekly_h100_forecast_per_cluster.py
```

## 6.1. Идея модели

В этой версии сохраняется та же логика short/long, но модели обучаются отдельно для каждого кластера.

Для каждого `cluster_id` обучаются две модели:

```text
cluster_{id}_short_macro
cluster_{id}_long_no_macro
```

Разделение по горизонту такое же:

```text
1–13 недель   -> short_macro
14–52 недели  -> long_no_macro
```

## 6.2. Отличие от глобальной версии

В глобальной версии:

```text
одна short-модель обучается на всех тикерах
одна long-модель обучается на всех тикерах
cluster_id является обычным признаком
```

В кластерной версии:

```text
для каждого кластера обучается своя short-модель
для каждого кластера обучается своя long-модель
модель видит только акции своего кластера
```

То есть кластеризация используется уже не только как признак, а как способ разделить задачу на несколько подзадач.

## 6.3. Потенциальные преимущества

Кластерная модель может лучше учитывать специфику групп акций: защитные акции, технологические акции, циклические акции, высоковолатильные акции, акции с похожей сезонностью и акции с похожей динамикой режимов.

## 6.4. Потенциальные недостатки

Главный недостаток — меньше данных на каждую модель:

```text
глобальная модель видит все 199 тикеров
кластерная модель видит только тикеры своего кластера
```

Из-за этого модели могут быть менее устойчивыми, а дальние горизонты могут прогнозироваться хуже.

# 7. Периоды обучения и проверки

В обеих версиях используется одинаковая временная схема.

## 7.1. Test/backtest период

```text
2025-05-08 — 2026-05-08
```

В этот период попадают целевые недели `target_week`.

## 7.2. Validation период

Validation берётся перед test-периодом:

```text
примерно 2024-05 — 2025-05
```

Он используется для подбора гиперпараметров XGBoost через Optuna.

## 7.3. Финальное обучение

Финальная модель обучается на данных, у которых:

```text
target_week < 2025-05-08
```

То есть тестовый год не попадает в обучение.

# 8. Сравнение результатов

## 8.1. Общие метрики

| Версия | WAPE | MAPE | MSE | MAE | RMSE |
|---|---:|---:|---:|---:|---:|
| Глобальная `two_models` | **17.32%** | **19.97%** | **54 571** | **48.13** | **233.61** |
| Per-cluster | 17.90% | 20.47% | 68 528 | 49.76 | 261.78 |

По общим метрикам глобальная версия пока лучше.

Основной вывод:

```text
кластерная версия не улучшила общий результат относительно глобальной,

```

## 8.2. Сравнение short/long частей

| Версия | Группа | Горизонты | WAPE | MAPE | RMSE |
|---|---|---:|---:|---:|---:|

# 9. Главные выводы

## 9.1. Глобальная двухмодельная версия пока лучше как финальная

Глобальная версия `two_models` остаётся лучшей по общим метрикам:

```text
WAPE = 17.32%
MAPE = 19.97%
```

Она лучше подходит как базовая финальная модель, потому что стабильнее на всём наборе акций.

## 9.2. Кластерная версия полезна как исследовательское развитие

Per-cluster подход показал, что специализация моделей по кластерам может улучшать качество на отдельных группах акций.

Особенно это видно на коротких горизонтах:

```text
short_macro:
global      WAPE = 9.95%
per-cluster WAPE = 9.84%
```

То есть для горизонтов 1–13 недель кластеризация дала небольшой выигрыш.

## 9.3. Главная проблема кластерной версии — long-модель

Для горизонтов 14–52 недели кластерная версия хуже глобальной:

```text
long_no_macro:
global      WAPE = 19.78%
per-cluster WAPE = 20.58%
```

Вероятная причина: внутри каждого кластера меньше обучающих данных, а дальний прогноз требует более устойчивой статистики.

## 9.4. Кластеры неоднородны по качеству

Кластеры `0`, `2`, `5`, `6` прогнозируются хорошо. Кластеры `3` и `4` дают основные ошибки.

Это означает, что кластерный подход лучше использовать не механически для всех кластеров, а избирательно.
