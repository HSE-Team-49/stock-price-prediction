# Прогнозирование цен акций с помощью линейных моделей

### Разделение данных
- Временное разделение (80% train, 20% test)
- Разделение по дате, а не случайно (избегаем утечки)

### Целевая переменная
**Логарифмическая доходность следующего дня:**

### Признаки 

#### Скользящие средние
- ma_log_20, ma_log_50, ma_log_250

#### Лаги доходности
- return_lag_1, return_lag_2, return_lag_3, return_lag_5

#### Волатильность
- volatility (std доходности за 20 дней)

#### Ценовые диапазоны
- daily_range = (High - Low) / Close
- high_open_diff = (High - Open) / Open
- open_low_diff = (Open - Low) / Low

#### Временные признаки
- day_of_week (0-4)
- month (1-12)

---

## Модели

| Модель | Тип регуляризации | Параметры |
|--------|-------------------|-----------|
| Linear Regression | Нет | - |
| Ridge | L2 | alpha=0.01 |
| Lasso | L1 | alpha=0.001 |
| ElasticNet | L1 + L2 | alpha=0.001, l1_ratio=0.5 |


## Результаты

### Сравнение моделей

| Модель | R² | RMSE | MAE |
|--------|-----|------|-----|
| Linear Regression | -0.0005 | 0.0524 | 0.0147 |
| Ridge | -0.0005 | 0.0524 | 0.0147 |
| Lasso | -0.0000 | 0.0524 | 0.0145 |
| ElasticNet | **0.0003** | 0.0524 | 0.0145 |

## Выводы

1. **Модели не могут предсказать доходность** (R² ≈ 0)  
   Это соответствует гипотезе эффективного рынка

2. **Точность предсказания знака ~52%**  
   Незначительно лучше случайного угадывания (50%)

3. **Линейные модели недостаточны** для финансовых временных рядов
