Набор скриптов для анализа акций США из CSV (data/prices_all.csv и/или покомпонентных CSV).

Скрипты

Кластеризация автоэнкодером + Agglo/K-Means
cluster_ae_gridsearch_fixed.py
— перебор гиперпараметров AE и кластеризации, выбор лучшего по Calinski-Harabasz (дальше: Silhouette ↑, Davies ↓, Recon MSE ↓). Есть поддержка CUDA.

Корреляции Пирсона/Спирмена + отчёты
stocks_correlations.py
— считает корреляции по доходностям, сохраняет CSV, интерактивный HTML с теплокартами и PDF (дендрограммы, теплокарты, топ-пары).
