
## Описание работы EDA_indexs.ipynb:

Анализ исторических данных по 20 основным американским рыночным индексам за период с 2008 по 2025 годы. Файл включает проверку качества данных, выявление аномалий, анализ динамики и корреляций между индексами.

## Содержание:

1. Проверка качества и целостности данных
2. Выявление выбросов и аномалий в данных
3. Анализ динамики цен индексов
4. Исследование корреляционных взаимосвязей между индексами
5. Формирование выводов для дальнейшей работы
