# Набор скриптов для класстеризации и поиска корреляций акций США из CSV (data/prices_all.csv и/или покомпонентных CSV).
- для получения файлов с данными и торгах и т.д. необходимых для запуска нужно посмотреть ноутбук в репозитории parcing_sahre_and_macro
- все вопросы по этому коду - tg @frashnigga

## Скрипты

1. Кластеризация автоэнкодером + Agglo/K-Means
— перебор гиперпараметров A и кластеризации, выбор лучшего по Calinski-Harabasz (дальше: Silhouette ↑, Davies ↓, Recon MSE ↓). Есть поддержка CUDA.

2. Корреляции Пирсона/Спирмена + отчёты
— считает корреляции по доходностям, сохраняет CSV, интерактивный HTML с теплокартами и PDF (дендрограммы, теплокарты, топ-пары).

## Библиотеки 
- pip install -U pandas numpy scikit-learn matplotlib torch tqdm plotly scipy
- (опционально) PyTorch с CUDA — по инструкции на pytorch.org

## Выходные файлы AE
- cluster_fullstart_assignments.csv — распределение по класстерам
- clusters_fullstart_report.pdf - pdf с графиками всех класстеров
- ячяйка после автонкодера содержит в себе код для запуска интерактивных графиков, где можно посмотреть все класстеры детально

## Выходные файлы после поиска корреляций
- corr_pearson_raw.csv, corr_spearman_raw.csv — исходные матрицы.
- corr_pearson_ordered.csv, corr_spearman_ordered.csv — упорядоченные матрицы.
- top_pairs_pearson.csv, top_pairs_spearman.csv — топ-N пар по |corr| (со знаком).
- correlations_heatmaps.html — интерактивные теплокарты (Plotly).
- correlations_report.pdf — PDF: сводка, 2 дендрограммы, 2 теплокарты, таблицы топ-пар.

## Краткие выводы
На данный момент собраны готовые рабочие скрипты для класстеризациии и поиска коэффициентов Спирмена и Пирсона. По метрикам для класстеризации можно сделать вывод , что уже на данный момент класстеризация сделана досточно хорошо, но для улучшения результата будет сделан более точный перебор гиперпарметров AE и учтены макроиндикаторы (так же их учёт позволит оценить их вляиние на рынок).
