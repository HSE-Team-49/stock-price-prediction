# Сборка проекта и запуск командой: docker compose up -d --build
## 1) Состоит из следующих частей:
- Frontend на Streamite (далее Frontend) 0.0.0.0:8501
- Backend на FastAPI (далее Backend) 0.0.0.0:8000
- MLflow Retrain 0.0.0.0:5000


# Frontend 
## Позволяет:
- Просмотреть график о исходных данных
- Сделать запрос на Backend о предскацании цены
- Отобразить результаты запроса


# Backend 
## Позволяет:
- Получить запросы от Frontend
- Обратиться к модели за предсказанием
- Выдать результаты предсказания
- Обратиться к MLflow для переобучения модели
- Выбрать из моделей активную
- Посмотреть метаданные о модели
- Посмотреть метрики

# MLflow 
## Позволяет:
- Сделать предсказание
- Переобучить модель
- Получить метаданные модели
- Получить метрики модели
