# Что внутри

- `docker-compose.yml` — поднимает `Postgres + MLflow + MinIO`.
- `nhits_stock_prediction.ipynb` — обучение NHITS модели с кластеризацией и логированием в MLflow.
- `cluster_analysis.ipynb` — кластеризация компаний на основе временных рядов (Autoencoder + Agglomerative Clustering).
- `load_prd_model.ipynb` — загрузка PRD модели из MLflow и тестовый предикт.
- `baseline_linear_model.ipynb` — сравнение с линейными моделями (Linear Regression, Ridge, Lasso).

## Требования

- Python `3.12+`
- [uv](https://docs.astral.sh/uv/) (или pip)
- Docker + Docker Compose
- GPU (рекомендуется для ускорения обучения)

## Быстрый старт

1. Установить Python-зависимости:

pip install -r requirements.txt

2. Поднять инфраструктуру MLflow:

docker compose up -d --build

3. Запустить Jupyter:

main.ipynb

### Анализ ошибок
1. ВЫСОКАЯ ВОЛАТИЛЬНОСТЬ (VST, MU, CEG, VRT, HOOD):
   - Причина: Резкие движения на новостях, не отраженные в истории
   - Корректировка: Добавить новостные признаки
   - Невозможность полной корректировки: Новости непредсказуемы

2. РАЗНЫЕ КЛАСТЕРЫ:
   - Причина: Разное поведение компаний в разных кластерах
   - Корректировка: Уже учтено через кластерные признаки

3. МАКРОЭКОНОМИЧЕСКИЕ ШОКИ:
   - Причина: Внешние факторы (инфляция, ставки)
   - Корректировка: Добавить макро-признаки

4. НИЗКАЯ ЛИКВИДНОСТЬ:
   - Причина: Мало данных для некоторых тикеров
   - Корректировка: Использовать больше истории
