# Walk-forward прогноз месячной доходности акций (XGBoost + CatBoost + Optuna, GPU)

Скрипт строит **месячную панель признаков** по дневным OHLCV-данным, подбирает гиперпараметры моделей через **Optuna** (только на train) и затем выполняет **walk-forward (expanding window)** тестирование на выбранном тестовом году.

Главная идея walk-forward в этом проекте:

* прошёл 1 месяц → модель обучилась на истории до него;
* прошёл 2 месяц → модель **переобучилась с нуля** на истории с самого начала до 2-го;
* прошёл 3 месяц → модель снова переобучилась на истории до 3-го;
* и так далее.

То есть **на каждом шаге веса/деревья пересчитываются на всё более длинной истории** (expanding window), что соответствует сценарию «данные поступают во времени, модель регулярно обновляется».

Это убирает тикеры с короткой историей, чтобы панель признаков строилась на сопоставимых временных рядах.

## 3) Постановка задачи

### 3.1) Переход к месячным данным

Из дневных OHLCV строятся месячные агрегаты:

* `Open` — первое значение месяца
* `High` — максимум месяца
* `Low` — минимум месяца
* `Close` / `Adj Close` — последнее значение месяца
* `Volume` — сумма объёмов за месяц

### 3.2) Что предсказываем

Используется **лог-доходность**:

* `ret(t) = ln(P(t)) - ln(P(t-1))`

Таргет:

* `target_next(t) = ret(t+1)`

То есть строка с датой `t` соответствует прогнозу **доходности следующего месяца**.

---

## 4) Признаки (features)

Формируются признаки на месячных данных:

### 4.1) Лаги доходности

Для `LAGS = [1, 2, 3, 6, 9, 12]`:

* `ret_lagL` = `ret(t-L)`

### 4.2) Скользящие статистики по доходности

Для `ROLL_WINDOWS = [3, 6, 12]`:

* `ret_roll_mean_W` — среднее
* `ret_roll_std_W` — std
* `ret_mom_W` — сумма доходностей (моментум)

### 4.3) ATR (Wilder)

Для `ATR_WINDOWS = [6, 12]`:

* `TR_t = max(High-Low, |High-PrevClose|, |Low-PrevClose|)`
* `ATR` сглаживается как Wilder EMA: `alpha = 1/W`

### 4.4) RSI (Wilder)

Для `RSI_PERIODS = [6, 12]`:

* RSI считается на лог-доходностях (эквивалентно работе с приращениями цены в лог-шкале)

### 4.5) Объём

Если доступен `Volume`:

* `vol_dln_1` — лог-изменение объёма
* `vol_roll_std_W` — rolling std лог-изменения объёма

### 4.6) Рыночный фактор

Рыночный фактор — средняя доходность по тикерам (equal-weight):

* `mkt_ret(t)`

И его лаги на `[1, 3, 6, 12]`:

* `mkt_ret_lagL`

### 4.7) Календарные циклические признаки

По номеру месяца:

* `month_sin`, `month_cos`

---

## 5) Разбиение на Train/Test

Логика задаётся параметрами:

* `TEST_YEAR = 2024`
* `TRAIN_END = 2023-12-31`

То есть:

* **Train**: все месяцы `<= TRAIN_END` (всё до 2024 года)
* **Test**: все месяцы, попадающие в `TEST_YEAR`

Важно: **Optuna подбирает гиперпараметры только на Train.**

---

## 6) Optuna: подбор гиперпараметров

### 6.1) Hold-out внутри Train

Внутри train делается валидация «последние 12 месяцев»:

* `tr` — всё кроме последних 12 месяцев
* `va` — последние 12 месяцев

Это используется только для подбора гиперпараметров, а **test-year не участвует**.

### 6.2) XGBoost (GPU)

* `device="cuda"`, `tree_method="hist"`
* подбираются: depth, eta, subsample, colsample, регуляризации и др.
* оптимизируется RMSE на hold-out (последние 12 месяцев train)

### 6.3) CatBoost (GPU)

* `task_type="GPU"`
* подбираются: depth, learning_rate, l2_leaf_reg, bagging_temperature и др.
* оптимизируется RMSE на hold-out (последние 12 месяцев train)

---

## 7) Walk-forward (expanding window) тестирование

После выбора гиперпараметров выполняется walk-forward по всей истории.

### 7.1) XGBoost: expanding retrain

Для каждого месяца `m`:

1. берётся накопленная история до `m` (месяцы `< m`)
2. XGB обучается **с нуля** на этой истории
3. делается прогноз для строк месяца `m`
4. месяц `m` добавляется в накопление

Сохраняются прогнозы только для месяцев `TEST_YEAR`.

### 7.2) CatBoost: expanding retrain с early stopping (ускорение)

CatBoost тоже переобучается **с нуля** на expanding-окне, но чтобы ускорить расчёты:

* внутри накопленного train делается hold-out на последние `holdout_months` месяцев
* обучение идёт с `use_best_model=True` и `od_type/od_wait` → **early stopping**
* итерации ограничиваются сверху параметром `max_iters_wf`

#### Логирование шага CatBoost

Функция печатает:

* текущий месяц (Period)
* сколько месяцев в накопленном train
* сколько строк в train
* сколько итераций реально использовано (`tree_count_`)
* время шага
* режим: `holdout+ES` или `no-holdout`
